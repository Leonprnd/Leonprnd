# De eerste 30 dagen

Een volgorde die voorkomt dat je geld uitgeeft aan advertenties voordat de rest
klaarstaat. De meeste winkels die mislukken, mislukken in week drie omdat ze in
week één met adverteren begonnen.

## Week 1 — regelen

| Dag | Wat |
|---|---|
| 1 | KVK inschrijven (€ 75). Zakelijke rekening aanvragen. |
| 1 | Drie monsters bestellen bij drie leveranciers. Doe dit vandaag: dit is de langste wachttijd in het hele traject. |
| 2 | Domeinnaam kopen. `winkel/bedrijf.json` invullen wat je al weet. |
| 3 | Vijf leveranciers aanschrijven met het bericht uit [inkoop](02-inkoop-en-leveranciers.md). |
| 4–5 | Algemene voorwaarden laten nakijken. Mollie aanvragen. |

## Week 2 — testen en bouwen

| Dag | Wat |
|---|---|
| 8–10 | Monsters komen binnen. Doe het volledige monsterprotocol en schrijf je metingen op. |
| 11 | Kies je leverancier. Bestel meteen twintig stuks. |
| 12 | Maak de foto's en de drie video's. Neem hier een hele dag voor. |
| 13 | Vervang de beelden in de winkel. Vul `verhaal.html` met je eigen, kloppende verhaal. |
| 14 | Testbestelling van begin tot eind. **Laat iemand van boven de 65 hem zonder hulp doen.** |

## Week 3 — de eerste klanten, zonder advertenties

Nog niet adverteren. Eerst vijf echte klanten, zodat je weet dat het hele proces
werkt en zodat je je eerste beoordelingen hebt.

- **Marktplaats.** Zet er twee advertenties op, één per uitvoering. Kost niets
  en levert je precies deze doelgroep.
- **Je eigen omgeving.** Vraag rond. Bijna iedereen kent iemand die dit kan
  gebruiken.
- **Facebook-groepen** rond mantelzorg en thuiszorg. Lees eerst de regels en ga
  niet spammen; vertel wat je doet en vraag om feedback.

Bij elke verkoop: bezorgen, opbellen, vragen wat er beter kan. Die vijf
gesprekken zijn meer waard dan € 500 aan advertenties.

## Week 4 — adverteren

Pas beginnen als dit allemaal waar is:

- [ ] Twintig stuks op voorraad of een leverancier die binnen vier dagen levert
- [ ] Vijf bestellingen zonder problemen afgehandeld
- [ ] Minstens drie echte beoordelingen op de site
- [ ] Mollie werkt, een echte betaling is gelukt
- [ ] Alle `[INVULLEN]` en `[VELDEN]` zijn weg
- [ ] Je telefoonnummer wordt tussen 9 en 17 uur opgenomen

Dan: € 25 per dag, twee weken, volgens [Facebook-advertenties](05-facebook-ads.md).

## Je dagelijkse rondje — vijftien minuten

1. **Bestellingen doorzetten** naar je leverancier
2. **E-mail en voicemail** afhandelen
3. **Advertentiecijfers bekijken** — alleen kijken. Niet elke dag aanpassen; dat
   is de meest gemaakte fout. Beslis om de twee dagen.
4. **Track & Trace** controleren op pakketten die vastzitten

## Wat je wekelijks bijhoudt

Één simpel overzicht, elke maandag:

| | Week 1 | Week 2 | Week 3 |
|---|---|---|---|
| Bestellingen | | | |
| Omzet | | | |
| Advertentiekosten | | | |
| ROAS | | | |
| Retouren | | | |
| Winst na alles | | | |

Die laatste regel is de enige die telt. Omzet is geen winst.

## Wanneer je stopt

Spreek dit met jezelf af **voordat** je begint, niet als je er middenin zit:

- **Na € 500 advertentiekosten** zonder een ROAS boven 2,5: stop met deze
  video's en maak nieuwe. Niet meer geld in dezelfde advertentie stoppen.
- **Na € 1.000** zonder een ROAS boven 2,5: stop met dit product. Je monsters
  en je kennis zijn niet weg — je weet nu hoe het werkt.
- **Retouren boven de 15%:** stop met adverteren en zoek uit waarom. Meestal is
  het je leverancier of een advertentie die te veel belooft.

## Wat er waarschijnlijk misgaat

Ter voorbereiding, zodat je niet schrikt:

- **Je eerste leverancier stelt teleur.** Vrijwel iedereen wisselt in de eerste
  drie maanden. Daarom bestel je monsters bij drie.
- **Je eerste advertentie doet niets.** Normaal. Daarom maak je er drie.
- **Iemand belt boos.** Neem op, luister, los het op. Bij deze doelgroep kan één
  goed opgelost probleem je drie nieuwe klanten opleveren.
- **Meta keurt een advertentie af.** Lees [de regels](05-facebook-ads.md)
  opnieuw. Ga niet in beroep met dezelfde tekst.
